# Changelog

## v0.1.0 (2026-10-11)
First tagged version (initial commit of the project).
- Data model (36 Prisma models), seed data and migrations.
- Order pipeline, suppliers, products, comparisons, margins, logistics, document checklists, analyses and admin settings.
- PDF generation (proforma invoice, purchase order, packing list) and Excel export.
- PHC connector layer with manual CSV import.

A full copy of the repository at this point is kept in the branch `backup/2026-10-11`.
